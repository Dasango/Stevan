# /docs — Guidelines

## 1. Scope & Responsibility
The `/docs` directory houses:
- Architectural specs and system topology diagrams.
- Interface contracts between modules.
- Step-by-step acceptance criteria, baseline metrics, and user approval logs.

## 2. Formatting Standards
- Standard GitHub Flavored Markdown (`.md`).
- Mermaid diagrams for state machines, sequences, and module architectures.
- Every step from the project plan must have an acceptance checklist document in `/docs/steps/step-<N>.md`.
